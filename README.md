

# cinema-booking
Application de réservation de cinéma

## Convention de nommage des branches

main : branche contenant la version stable de l'application.

develop : branche d'intégration des nouvelles fonctionnalités.

feature/nom-fonctionnalite : pour développer une nouvelle fonctionnalité.

fix/nom-correction : pour corriger un problème.

hotfix/nom-correction-urgente : pour corriger rapidement un problème critique.

## Règles à respecter

Utiliser des lettres minuscules.

Séparer les mots par des tirets (-).

Utiliser un préfixe adapté au type de travail.

Éviter les espaces et les accents.

## Exemples

feature/recherche-films

feature/reservation-seances

fix/selection-sieges

hotfix/erreur-paiement

## Installation et lancement

npm install
npm start
npm test
npm run lint
